# lagerverwaltung.js

Ein einfaches JavaScript-Skript zur Verwaltung von Produkten in einem Lager.

## Funktionen

* **Produkt hinzufügen:** Fügt ein neues Produkt mit ID, Name, Nummer und Kosten hinzu.
* **Gesamtkosten berechnen:** Berechnet die Gesamtsumme aller Produktkosten.
* **Produkte prüfen:** Findet Produkte, die zur Neige gehen (Nummer unter 100).
* **Produktsuche:** Sucht ein Produkt anhand des Namens.
* **Produkt löschen:** Entfernt ein Produkt aus der Liste.

* ## Verwendung

Das Skript kann direkt in einer JavaScript-Umgebung oder Node.js ausgeführt werden.
